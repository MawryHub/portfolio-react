# Portfolio React

A simple React landing page for a CV and portfolio built with Vite.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```

## Next steps

- Add a CSS framework like Tailwind or Chakra UI. Tailwind is already configured in this project.
- Add real project cards, skills, and resume content.
- Deploy to GitHub Pages or Vercel.
